# מתכונים

ספר המתכונים של המשפחה – כל המתכונים מקבוצת הוואטסאפ במקום אחד.

האתר: https://matkonim.nimrodyaroker.workers.dev

- רץ על Cloudflare Workers (החשבון של נמרוד), עם מסד נתונים מובנה.
- כל שינוי שנשמר בריפו הזה עולה לאתר אוטומטית.
- המתכונים מהקבוצה נמצאים ב-`src/seed.json` ונכנסים לאתר פעם אחת. מתכון חדש שנוסף לקובץ (עם id חדש) נכנס אוטומטית.
